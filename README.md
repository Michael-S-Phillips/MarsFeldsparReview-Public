# Data and code: Evolved and Feldspathic Igneous Rocks on Mars

Companion archive for Phillips, Viviano, and McSween, *Evolved and Feldspathic Igneous Rocks on Mars: A Review of
Detections, Formation Hypotheses, and Implications for Early Crustal Evolution* (Space Science Reviews).

The archive holds the CRISM ratio spectra, region-of-interest (ROI) definitions, and tables behind the paper's
reassessment of published feldspathic detections (Supplementary Table 1) and its new detections (Supplementary
Table 2), and the code that draws the spectral figures from them.

## Contents

| Path | Content |
|---|---|
| `data/tables/` | Supplementary Tables 1 and 2 as CSV (one row per ROI) |
| `data/detections/literature_detections.csv` | Published CRISM feldspathic detections compiled for the review (observation, location, interpretation, reference) |
| `data/detections/figure_*.csv` | Region codes and class categories used by the figure code to group spectra |
| `data/spectra/` | ENVI spectral libraries of ratio and unratioed numerator spectra (see below) |
| `data/crism/` | Spectra extracted in this work from MTRDR cubes (`.npz`) |
| `data/rois/` | ROI tables of the CSI extraction, Viviano-Beck et al. (2017) ROIs, and the polygon ROIs of FRT00018FF2 and FRT00004185 (GeoPackage) |
| `data/fig1/` | Projected marker positions for the Fig. 1 map and insets |
| `scripts/figures/` | Figure code |
| `scripts/extraction/` | Spectrum extraction from MTRDR cubes |
| `scripts/tables/sample_dci.py` | Recomputes the DCI column of the tables |

## Reproducing the figures

```
conda env create -f environment.yml
conda activate mars-feldspar-review
bash scripts/make_figures.sh        # writes output/
```

| Figure | Script | Inputs |
|---|---|---|
| Fig. 4 | `scripts/figures/plot_confidence_criteria_r3.py` | `data/spectra/`, `data/crism/confidence_criteria_r3_spectra.npz` |
| Figs. 5–9 | `scripts/figures/plot_spectra_r2.py` | `data/spectra/`, `data/crism/`, `data/detections/figure_*.csv` |
| Supplementary Fig. 2 | `scripts/figures/plot_supp_fig2_ratio_cr.py` | as Figs. 5–9 |
| Fig. 1 map layers | `scripts/figures/fig1_layers.py` | `data/detections/literature_detections.csv`, `data/tables/`, and the HRSC–MOLA blended DEM (Fergason et al., 2018; not included) |

`plot_spectra_r2.py` and `plot_confidence_criteria_r3.py` reproduce the published PNGs pixel for pixel. Fig. 1
and Fig. 2 were composed in a drawing tool from the map layers and marker positions in `data/fig1/`. Fig. 3,
Fig. 10 (compiled from the cited literature), Figs. 11 and 12 (illustrations), and Supplementary Fig. 1 (a
separate MRDR mapping effort) are not generated by code in this archive.

## Conventions

**Pixel coordinates.** ROW and COL in the tables are 1-based, non-map-projected (sensor) coordinates: the IR Line
and IR Sample values of the MTRDR IN backplane plus one. A ROI of ROWS × COLS pixels is centered on (ROW, COL);
its spectrum is the mean I/F of the map-projected pixels whose IN values fall inside that sensor-space box. Each
ratio spectrum is the numerator mean divided by the denominator mean from the same detector column.

**Polygon ROIs.** The FRT00018FF2 and FRT00004185 ROIs are irregular polygons drawn on the map-projected MTRDR
(`data/rois/*.gpkg`; polygon numbers match the `#n` of the spectrum names). For these rows, ROW and COL give the
polygon centers and `roi_pixels` gives the number of map-projected pixels in the numerator polygon.

**Classes.** High, moderate, and low confidence, nd (no detection), other endmember, and No MTRDR are defined in
Section 2.3.1 of the paper and in the footnote of Supplementary Table 1. In the CSV files, blank cells of
continuation rows are filled from the row above for the same observation, as in the printed tables; the
`footnote` column carries the table footnote marks (Supplementary Table 1: c, no MTRDR in the PDS, made from TRDR
data; d, polygon ROI; *, alteration mineral also reported by Viviano-Beck et al., 2017. Supplementary Table 2: a,
polygon ROI).

**Spectral libraries.** Names follow `<CRISM ID>_07_#<ROI>_<label>`. The label is the one assigned when the
spectrum was extracted; the class used in the paper is the one in the tables. Libraries:

- `plag_confident`, `dusty_plag`, `other_endmem_mafic`, `other_endmem_alteration`, `nd`: reassessed literature ROIs
- `plag_confident_new`, `other_endmem_alteration_new`: new detections (Supplementary Table 2)
- `r1_csi_ratioed`, `r1_csi_on`, `r1_csi_off`: ratio, numerator, and denominator spectra of every Supplementary
  Table 1 ROI (CSI extraction by C. E. Viviano); ROI pixels in `data/rois/csi_literature_rois.csv` and in the tables
- `unratioed_*`: numerator spectra shown in the right-hand panels of Figs. 5–9
- `no-plot/`: alternative ratios not shown in the paper

Most library spectra of Supplementary Table 1 ROIs are identical to the CSI spectra of the same ROIs; the few
that differ (HRL0000985E in `plag_confident_new` and the `no-plot/` ratios) are earlier extractions, and the
figures use the CSI versions.

**Spectra extracted in this work** (`data/crism/`): HRL0000638C ROI 1 at its sensor ROI (Fig. 8);
the six Viviano-Beck et al. (2017) observations at the 2017 ROIs (Fig. 8c, d); FRT00004B38 and FRT0000426F
(Supplementary Table 2); and the numerator and denominator spectra of Fig. 4.

## Re-extracting spectra

The extraction scripts read MTRDR cubes from the PDS Geosciences Node (`mro-m-crism-5-rdr-mptargeted-v1`); put
each `<id>_07_if*_mtr3/` folder (IF cube, IN and DE backplanes) under one directory and set `CRISM_MTRDR_ROOT`.

```
python scripts/extraction/roi_tools.py box  $CRISM_MTRDR_ROOT/frt00004b38_07_if164j_mtr3 45 81 84 81 5 7 -o 4B38.npz
python scripts/extraction/roi_tools.py polygon data/rois/FRT00004185_polygon_rois.gpkg $CRISM_MTRDR_ROOT/frt00004185_07_if165j_mtr3 4
python scripts/extraction/extract_viviano2017_mtrdr.py $CRISM_MTRDR_ROOT out/
```

`scripts/tables/sample_dci.py` recomputes the DCI column from the TES dust cover index map (Ruff and Christensen,
2002), which is not redistributed here.
